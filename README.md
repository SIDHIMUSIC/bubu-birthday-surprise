# Bubu's Birthday Website ♡

A one-off, responsive birthday surprise for Bubu from Harry. Birthday: 13 December 2026.

## Add your photos
Upload your photos into the `images/` folder with these exact names:
`jpg1.jpg`, `jpg2.jpg`, `jpg3.jpg`, `jpg4.jpg`, `jpg5.jpg`.
Optional slots: `jpg6.jpg` through `jpg10.jpg`.

## Add the romantic song
Upload the chosen audio file to `audio/music.mp3`. Browsers require a visitor tap before music can start.

The provided LoveArea URL is a birthday template collection, not one specific preview, so it does not identify one exact track. Add the song file you want to use as `music.mp3`.

## Deploy on Vercel
Import this GitHub repository into Vercel. Select **Other** as framework preset, leave build command blank, and use `.` as output directory. No build step is required.
